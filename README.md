* Responsive design

* Skills section
* Projects showcase
* Contact section
* Modern UI

## 📂 Installation

Clone the repository:

```bash
git clone https://github.com/nishant1800/Portfolio.git
```

Go to the project folder:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## 📦 Build

To create a production build:

```bash
npm run build
```
